# Mappa Milano — demo campagna

Demo del gestionale visite per il candidato sindaco (lavoro per Keymove).
Mappa 2D e 3D di Milano con 1.621 luoghi, filtri per categoria e Municipio.

- In questa demo le modifiche si salvano **solo nel browser** di chi le fa.
- Dati edifici: Comune di Milano, Database Topografico 2020 (CC BY 4.0); Overture Maps; © OpenStreetMap contributors (ODbL).
- Modelli 3D dei monumenti: realizzati internamente.
